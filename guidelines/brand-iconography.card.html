PROVENANCE
The path data in QM_ICONS is copied from lucide (ISC licence, same 24×24 / 2px / round-cap convention). Inlining it — rather than depending on lucide-react — is deliberate: QM ships no runtime icon dependency. A consumer may re-point Icon at lucide, but must read the table below first: two keys are renames and four have no lucide equivalent, so they will change appearance silently.

rounded means the lucide path with coordinates cut to one decimal — same shape. unfold is a QM composite, not a stale lucide copy: two outline rules under a fold control, drawn for the Outline rail's Expand / Collapse all toggle. No lucide glyph carries that reading, so it stays custom and keeps its key. Need a glyph QM lacks? Copy it from lucide and add its row here — never draw a new one.
